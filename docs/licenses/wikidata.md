- **Teknik not:** SPARQL GET/POST, çıktı JSON/CSV/TSV vb. (Accept başlığı). Politika gereği: açıklayıcı User-Agent + iletişim bilgisi (ör. `country-info/x.y (https://…; mail)`), eşzamanlılık ≤ 5 (öneri: 1–2), 429'da Retry-After'a uy, sorguları sayfalayıp 60 sn altında tut; `FILTER(REGEX())` anti-pattern. Büyük/tam çekim (tüm P131 ağacı, tüm etiketler) için JSON dump + yerel filtre tercih edilmeli; WDQS dar kapsamlı sorgular (ülke başına) için.
